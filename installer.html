Installer Verso sur Android

Application personnelle · fichier APK de 3,5 Mo

Télécharger Verso.apk

Ouvrez cette page dans Chrome sur votre téléphone.

  1. Touchez Télécharger Verso.apk, puis confirmez si Chrome le demande.
  2. Ouvrez le fichier téléchargé (notification ou application Fichiers → Téléchargements).
  3. Android demande d'autoriser l'installation depuis Chrome ou Fichiers : Paramètres → Autoriser, puis revenez en arrière.
  4. Touchez Installer. Pour une mise à jour, l'installation se fait par-dessus : vos données sont conservées.
Le fichier s'appelle « Verso.zip » ?
Une APK est techniquement une archive zip, et certaines applications la renomment. Ne l'ouvrez pas comme un zip : renommez-la en Verso.apk dans l'application Fichiers (appui long → Renommer), puis touchez-la pour l'installer. Évitez le bouton « Code → Download ZIP » de GitHub, qui télécharge tout le projet et non l'application.
